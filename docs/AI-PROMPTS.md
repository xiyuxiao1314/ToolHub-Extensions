# AI 提示词 1.2.0

离线扩展 `community.ai-prompts`，需要 ToolHub **0.3.0-beta.8** 或更新版本。在「扩展中心 → AI 提示词」打开。

默认是空白库，不附带示例提示词。通过新增或导入建立自己的预设，分类从实际条目中生成。升级扩展会保留用户已保存的提示词；不会替其他用户自动清空已有内容。旧版本源码作为历史版本保留。

## 使用

- **新增**：填写标题、分类、可选标签与摘要，以及正文；正文支持 Markdown 纯文本。
- **编辑、删除**：卡片上直接操作，删除需要确认并可立即撤销。删除只移除库内记录，原始文件不受影响；撤销只在当前页面有效。
- **导入**：选择 UTF-8 .md/.markdown/.txt，或本扩展导出的 JSON 预设包。普通 Markdown 用首个一级标题或文件名命名；ToolHub Markdown 还原分类、标签、摘要和 ID。确认预览前不会写入。
- **冲突处理**：相同 ID 或同分类同名条目视为重复，完全相同的内容自动跳过；可保留现有、以导入覆盖或另存副本，默认保留现有。
- **导出**：详情内单条导出为 .md；「导出全部」生成 toolhub-prompts.json，可分享给另一台 ToolHub 导入。

本机保存成功后才提示成功。存储使用包专属命名空间与修订号，防止两个窗口静默覆盖。出错时保留草稿；清除 WebView 配置会移除本机提示词，重要内容请先导出。卸载扩展保留存储命名空间。

## 范围与验证

最多 500 条、合计 1 MiB UTF-8 JSON；正文最多 20,000 字符。每批导入最多 50 个文件、合计 2 MiB；导出最多 2 MiB。不执行 Markdown/HTML，不联网、不调用模型或工具，不含账号、收藏、发布或社区服务。原生保存窗口由用户选择位置；扩展不能自行指定磁盘路径。

源码位于 packages/ai-prompts/1.2.0/src。运行版本目录中的 build.py 重建包，运行 scripts/test-ai-prompts.mjs 验证数据，再运行 scripts/register-ai-prompts.py 和 scripts/validate.py 更新/检查目录。独立 preview.html 只在内存中演示，刷新重置。

数据验证覆盖默认空库、合成模板往返、Unicode/BOM/CRLF、重复冲突、空库持久化、非法与超限输入。Windows WebView 验证新增、卡片编辑/删除、确认取消、撤销和重新加载。回归方法见 [卡片操作验证](AI-PROMPTS-CARDS-VERIFICATION.md)。原生导出保存窗口端到端及 macOS 实机仍未验证。
