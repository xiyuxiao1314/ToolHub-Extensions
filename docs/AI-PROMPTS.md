# AI 提示词 1.1.1

独立离线扩展 `community.ai-prompts`，需要 ToolHub **0.3.0-beta.8** 或更新版本。该宿主版本补充了本机预设容量和受限文档导出接口。1.0.0 包仍保留，不能在旧宿主上直接安装 1.1.1。

## 使用

在「扩展中心 → 扩展应用 → AI 提示词」打开。48 条原创模板覆盖开发、设计、写作、办公、学习和 Agent 协作；分类与搜索、名称排序、分页、全文复制和键盘导航保留。

- **新增**：填写标题、分类、标签、摘要和正文。分类可以自定义，正文是纯文本，支持 Markdown 写法。
- **编辑**：直接点击卡片上的「编辑」修改。内置模板也可以编辑或移除。
- **删除**：直接点击卡片上的「删除」，确认后从库中移除，底部可立即撤销。原始文件不会被删除；撤销只在当前页面有效。
- **导入**：选择 UTF-8 的 .md/.markdown/.txt 或本扩展导出的 .json，可一次选择多份文件。普通 Markdown 用首个一级标题或文件名作为名称，正文原样保留；ToolHub 导出的 Markdown 同时还原分类、标签、摘要与 ID。
- **导入预览**：文件全部解析成功后才显示预览，确认后整体保存。相同 ID 或同分类同名条目视为冲突；完全相同的条目自动跳过。可选保留现有、以导入覆盖或另存副本，默认保留现有。不会因为导入失败写入一半数据。
- **导出单条**：详情中的「导出 .md」保存带有元信息的 Markdown 文件，可阅读、编辑并导回。
- **导出全部**：保存 toolhub-prompts.json，包含当前全部模板及修改。在另一台安装相同扩展和配套宿主的 ToolHub 上点击「导入」即可预览收录。

本机保存成功后才显示成功提示。宿主使用包专属存储和修订号，防止两个窗口静默覆盖。若存储不可用或并发冲突，显示错误并保留当前编辑草稿；重新打开页面后再处理。清除 ToolHub 的 WebView 配置会移除本机提示词，重要内容请导出备份；卸载扩展保留该命名空间。

## 边界

最多 500 条、合计 1 MiB UTF-8 JSON；单条正文最多 20,000 字符。每批导入最多 50 个文件，合计最多 2 MiB；导出最多 2 MiB。不会执行 Markdown/HTML、加载图片、请求网络、调用模型、登记 Skill 或启动工具。导出由宿主原生保存对话框选择位置；扩展不能自行指定磁盘路径。取消导出不改变库内容。

不含账号、收藏、发布或社区后台。独立 preview.html 只在内存中演示，刷新会重置；ToolHub 内才提供本机持久化与原生导出。不要把浏览器预览当作已安装版本。

## 开发与验证

源文件位于 packages/ai-prompts/1.1.1/src，保留原版 48 条模板。示例内容为本项目原创，MIT；仅功能理念参考 AI Short，未复制其数据或服务。

```powershell
python packages/ai-prompts/1.1.1/build.py
node scripts/test-ai-prompts.mjs
python scripts/register-ai-prompts.py
python scripts/validate.py
node scripts/preview-ai-prompts.mjs
```

数据测试覆盖 48 条 Markdown 往返、整库 JSON、BOM/CRLF/Unicode、重复与冲突策略、空库保存及非法/超限输入。Windows ToolHub 独立 WebView 已实测新增、编辑、删除撤销、重载持久化、Markdown 文件导入；修复了 sandbox 禁止 form 提交导致保存无效的问题。宿主存储隔离/修订/容量与真实 UTF-8 文件写入、文件名/目录拒绝测试通过。
